yt-dlp itself

Installed: …

Updates the downloader itself: a pip setup upgrades in place, and packaged builds fetch the newest release from PyPI (verified) and apply it on the next start. It is what knows the sites — the engine around it rarely changes. New jobs may wait a moment while it runs.
