# The palette — colour audit and plan (2026-11)

Written by Argon High against a read-only clone at v0.47.31, then checked line
by line against this tree. The ring diagnosis and the token tables shipped
almost as written; the differences are noted at the end.


## 1. Verdict on the Weird Ring & Pale Rectangle (Problem 1)
- **Ring Root Cause** (`style.css:1315, 274-277`): `.swatch.on` pairs `border-color: var(--accent)` with `box-shadow: 0 0 0 3px var(--accent-soft)` (`style.css:1315`). Under AMOLED + Pine (`style.css:95-102, 147-154`), `--bg` is `#000000`, `--accent` is cream `#F2E9D8`, and `--accent-soft` is `rgba(242,233,216,.14)`. On `#000000`, this 1px cream border plus 3px spread halo inflates to a fuzzy 4px outer glow mimicking a stuck focus ring. Focusing adds `outline: 2px solid var(--ring, var(--accent)); outline-offset: 2px` (`style.css:274-277`), directly colliding with the 3px box-shadow. In Light + Pine, `--ring` is not overridden (`style.css:76, 140-146`), painting a pine border (`#0e352b`) with a clashing amber-brown outline (`#8a5410`).
- **Rectangle Owner** (`style.css:468-479, 1289-1292`, `index.html:447`): Owned by `<section class="card">` inside `#panel-settings`. Under `liquid` glass, `.card` receives `background-image: var(--glass-gloss)` (`style.css:166, 1618`), `--glass-border: var(--accent-line)` (`rgba(242,233,216,.45)`, `style.css:151, 167`), and `--glass-hi` (`rgba(255,255,255,.24)`). Crucially, `#panel-settings .card` disables its own blur via `backdrop-filter: none` (`style.css:1289-1292`) to prevent nested-blur compounding over the sticky Save strip (`style.css:1269-1288`). On AMOLED `#000000`, this card becomes a raw, unblurred pale slab with a cream border sitting directly behind `.subtabs` (`style.css:1235-1248`). Additionally, `body::before` (`style.css:208-214`) paints a 1000px radial `--lamp` (`rgba(242,233,216,.08)`, `style.css:153`) bleeding through `header` and `.tabs` (`style.css:282-326`).
- **The Fix**:
  1. *Selected Swatch* (`style.css:1315, 1319`): Replace the outer spread halo with an inset ring at the same 12px radius: `border-color: var(--accent); background: var(--accent-soft); box-shadow: inset 0 0 0 1px var(--accent);` (and `var(--accent2)` in Light).
  2. *Focus Ring* (`style.css:274-277`): Reserve the outer ring strictly for `:focus-visible` (`outline: 2px solid var(--ring, var(--accent)); outline-offset: 2px`). Define `--ring: var(--accent2)` in `html[data-accent="pine"][data-theme="light"]`. Never mix two ring colours.
  3. *AMOLED Pale Slab*: Mute `--lamp: transparent` in AMOLED (`style.css:132`) and suppress `--glass-gloss` / keep border neutral (`var(--line)`) on `#panel-settings .card`.

## 3. Android Material You Plan (API 31+) (Problem 3)
- **Kotlin Call Shape & Payload** (`MainActivity.kt:353-530`):
  Add `@JavascriptInterface fun dynamicPalette(): String` to `HostBridge` (`MainActivity.kt:353`). Pre-API 31 returns `""`. On API 31+, resolve `android.R.color.system_accent1/2/3_*` and `system_neutral1/2_*` with `ContextCompat.getColor()` to JSON: `{"a1":{"100":"#..","200":"#..","600":"#..","700":"#..","800":"#.."},"a2":{"200":"#.."},"n1":{"50":"#..","100":"#..","800":"#..","900":"#.."},"n2":{"200":"#..","600":"#..","700":"#.."}}`. In `MainActivity.onResume()`, push `webView.evaluateJavascript("window.onDynamicPaletteChanged?.()", null)` on wallpaper change.
- **CSS Token Mapping** (`style.css:26-133`, `app.js:1502-1521`):
  JS calculates RGBA triplets and sets `--dyn-*` variables on `:root` (pre-computed `rgba()` prevents `color-mix()` rendering bugs on older WebViews). Under `html[data-accent="dynamic"]`:
  - *Light*: `--bg: n1_50`, `--panel-solid: n1_10`, `--text: n1_900`, `--muted: n2_700`, `--glass-bg: rgba(n1_10,.68)`, `--accent: a1_600`, `--accent2: a1_700`, `--accent-fg: n1_10`, `--accent-ink/#ring: a1_700`, `--accent-soft: rgba(a1_600,.14)`.
  - *Dark*: `--bg: n1_900`, `--panel-solid: n1_800`, `--text: n1_100`, `--muted: n2_200`, `--glass-bg: rgba(a2_200,.06)`, `--accent: a1_200`, `--accent2: a1_100`, `--accent-fg: a1_800`, `--accent-ink/#ring: a1_200`, `--accent-soft: rgba(a1_200,.15)`.
  - *AMOLED*: Retains `--bg: #000000`, `--bar-bg: rgba(0,0,0,.85)`, `--shadow: 0 0 #0000`, `--lamp: transparent`, paired with Dark text `n1_100`, glass `rgba(a2_200,.05)`, and accent `a1_200`.
  - State signals (`--ok`, `--err`, `--warn`) and `--glass-blur` never repaint.
- **Settings Affordance & Fallback Ladder** (`index.html:495-505`, `app.js:1522-1540`):
  Add swatch `<button class="swatch hidden" id="swDynamic" data-accent="dynamic">` ("Follow wallpaper"). Unhidden via JS only if `AndroidHost.dynamicPalette()` is non-empty. Precedence: manual selection (`amber`, `pine`, `cobalt`, etc.) overrides wallpaper; choosing "Follow wallpaper" activates dynamic mode. Ladder: API 31+ palette -> fallback to stored manual scheme -> fallback to `"amber"` (`index.html:18`, `app.js:1570`).

## 4. Acceptance Criteria & Verification
- **Static File Tests** (pinned via `tests/test_web_theming.py`):
  1. `.swatch.on` (`style.css:1315`) contains `inset 0 0 0 1px` and zero `0 0 0 3px` outer spreads; every light accent block defines `--ring`.
  2. Parse all scheme blocks in `style.css`: assert WCAG AA contrast (`--accent-ink` vs `--bg` >= 4.5:1, `--accent-fg` vs `--accent` >= 4.5:1, `--accent` vs `--bg` >= 3.0:1) and zero overrides of `--ok`, `--err`, `--warn`.
  3. Kotlin unit test: `dynamicPalette()` returns `""` on API <31; JS unit test: `CURRENT.accent` defaults to `"amber"` if bridge is absent.
- **On-Device Verification**:
  1. Switch to AMOLED + Liquid + Pine & cream: verify swatches display a crisp 1px inset ring with no outer halo, `:focus-visible` adds a single outer ring, and no pale slab appears behind `.subtabs`.
  2. On Android 12+ device: choose "Follow wallpaper", toggle Light / Dark / AMOLED, swap wallpaper, and verify live re-theming on resume with intact backdrop blur.

## 5. Risks & Mitigations
- **Contrast**: User wallpapers vary widely. Fixed tonal steps (`n1_900` on `n1_50`, `n1_100` on `n1_900`, `a1_800` on `a1_200`) guarantee >=4.5:1 by Material 3 HCT math. Belt-and-suspenders: clamp `--accent-fg` via JS luminance check.
- **Backdrop-Filter Roots** (`style.css:367-405, 1289-1292`): Never animate opacity/filter on `<html>` or ancestor wrappers during palette transitions; reuse `html.theming` (`style.css:1588-1590`, transitions only color/background/border) so no backdrop root kills glass frost.
- **WebView API Gaps**: Pre-compute RGBA strings in JS instead of CSS `color-mix()` (`style.css:1632`), guaranteeing compatibility on un-updated Android 12 WebViews (Chrome 92+).
- **Re-render Overhead**: Cache `lastPaletteJson` in JS; skip DOM updates and `html.theming` class if palette JSON is identical on resume.
- **Translations**: Add "Cobalt", "Oxide", "Silver", "Wallpaper", and "Follow my wallpaper" to `STRINGS.id` (`app.js:2000-2400`) with `data-i18n` on swatch elements.

## Summary
1. **The Ring & Rectangle** (`style.css:76, 140-154, 274-277, 468-479, 1289-1292, 1315`): `.swatch.on`'s outer `box-shadow: 0 0 0 3px` creates a fuzzy halo on AMOLED `#000000` and collides with `:focus-visible` (`--ring` was unassigned in Light+Pine), while `#panel-settings .card` (`backdrop-filter: none` + `liquid` `--glass-gloss` + `--accent-line`) forms the pale slab behind `.subtabs`. Fix: use `box-shadow: inset 0 0 0 1px` for `.swatch.on`, assign `--ring: var(--accent2)` in all light accents, and mute gloss/lamp in AMOLED.
2. **Three Schemes Worth Shipping**:
   - `cobalt` (Nitrate Blue): reference CRT monitor `#6eb0ff` (dark) / `#1858b8` (light); high clarity against state LEDs.
   - `oxide` (Splicing Tape): warm analog magnetic tape `#f09a72` (dark) / `#9e4722` (light); distinct from `--err` rose.
   - `silver` (Halide Mono): technical monochrome `#d8dee6` (dark) / `#2c3138` (light); lets state signals pop.
3. **First Step for Material You**: Add `@JavascriptInterface fun dynamicPalette(): String` to `MainActivity.HostBridge` (`MainActivity.kt:353`) returning API 31+ tonal hex steps, then map them in `app.js` (`applyTheme`) to `--dyn-*` RGBA tokens under `html[data-accent="dynamic"]`.

## What shipped, and what changed from the plan

- **The ring.** Argon named `.swatch.on`'s 1px `--accent` border + 3px
  `--accent-soft` halo and the missing `--ring` per theme. Both shipped. The
  owner's "pale rectangle" was the settings card: the one slab with no frost
  still carried the *glass* border and gloss, which on AMOLED reads as a slab
  behind the tab strip. It now takes `--line` and no gloss.
- **Schemes.** Cobalt, Oxide and Silver shipped with the token tables above.
  Amber and Pine were left untouched: changing an existing scheme is a
  different release from adding one.
- **Material You.** Shipped as the `dynamic` accent: `HostBridge.dynamicPalette()`
  returns the light and dark tonal steps on API 31+, `""` below it, and the page
  hides the Wallpaper swatch when there is nothing to follow. The CSS blocks
  read `--dyn-*` tokens with static fallbacks, so a broken bridge cannot leave
  the UI unstyled — it falls back to the cobalt values.
- **Not taken.** Argon's suggestion to add a sixth "paper" scheme: five plus
  wallpaper is already two rows of swatches; a sixth would push the Save button
  below the fold on a 412 pt phone.
